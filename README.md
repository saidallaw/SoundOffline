# ساوند أوفلاين (SoundOffline)

تطبيق أندرويد للكتب المسموعة والبودكاست: رابط يوتيوب أو ساوند كلاود (فيديو/مقطع أو قائمة) أو Share من التطبيقين → يتحمل الصوت أوفلاين → تشغّله بسرعة 1x / 1.25 / 1.5 / 1.75 / 2 / 2.25 / 2.5.

- **مكتبتي**: القوائم بتتجمع ككتاب واحد بأجزاء، وبتشتغل ورا بعض أوتوماتيك، مع نسبة اللي سمعته و«كمّل الاستماع»
- **اقتراحات**: مقترحات من الفيديوهات المرتبطة باللي حمّلته + بحث في يوتيوب (مع أزرار سريعة: كتاب مسموع، رواية مسموعة…)
- **الفصول**: لو فيديو يوتيوب فيه chapters تقدر تتنقل بينها
- **مؤقت النوم**: 15/30/45/60 دقيقة أو آخر الفصل/الجزء

- تشغيل في الخلفية والشاشة مقفولة + تحكم من النوتيفيكيشن وشاشة القفل
- بيفتكر آخر مكان وقفت عنده في كل مقطع
- بيفتكر السرعة اللي اخترتها
- تقديم 30 ثانية / رجوع 15 ثانية

## بناء الـ APK (من غير Android Studio)
1. اعمل repo جديد على GitHub وارفع محتويات الفولدر ده (Add file → Upload files، واسحب الفولدرات كلها بما فيها `.github`).
2. روح تبويب **Actions** → هتلاقي "Build APK" شغال (أو دوس Run workflow).
3. لما يخلص (~5 دقايق) افتح الـ run ونزّل **SoundOffline-apk** من Artifacts، فك الـ zip وثبّت `app-debug.apk` على الموبايل (اسمح بالتثبيت من مصادر غير معروفة).

## أو بـ Android Studio
File → Open → اختار الفولدر → Run.

## لو يوتيوب وقف
يوتيوب بيغيّر نظامه كل فترة. افتح `app/build.gradle.kts` وغيّر رقم `NewPipeExtractor:v0.26.5` لآخر إصدار من
https://github.com/TeamNewPipe/NewPipeExtractor/releases وارفع التعديل — GitHub هيبني APK جديد.

## ملاحظات
- مقاطع Go+ المدفوعة متاح منها معاينة 30 ثانية بس، فالتطبيق بيرفضها.
- التطبيق بيستخدم API الويب بتاع ساوند كلاود (مش API رسمي)، فلو ساوند كلاود غيّروا حاجة ممكن يحتاج تحديث.
